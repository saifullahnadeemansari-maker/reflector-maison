# REFLECTOR

Premium Geneva watch maison site. Light, held in time.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

1. Open https://vercel.com/new
2. Import this GitHub repo: `saifullahnadeemansari-maker/reflector-maison`
3. Framework: Next.js (auto)
4. Deploy

Header button **Device look** switches iPhone / Android / MacBook / Laptop / Computer themes.
